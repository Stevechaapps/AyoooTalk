# Security policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/Stevechaapps/AyoooTalk/security/advisories/new).
Do not open a public issue for a vulnerability.

Include:

- the affected version,
- the Android version and device model,
- steps to reproduce,
- the impact you believe it has.

## Supported versions

Only the latest release receives fixes. The current version is listed in
[Releases](https://github.com/Stevechaapps/AyoooTalk/releases).

## Scope

In scope: the Android app, the signaling service behind `ayoootalk.com`, and
the release binaries published here.

Out of scope: your carrier's network, your device firmware, and third-party
services such as Firebase Cloud Messaging.
