# Ayooo 1.4.10

Free, encrypted 1:1 voice and video calls for Android — no phone number, no ads,
no analytics.

## Download

- [Ayooo.apk](https://github.com/Stevechaapps/AyoooTalk/releases/latest/download/Ayooo.apk) — universal, ~27 MB
- [SHA256SUMS.txt](https://github.com/Stevechaapps/AyoooTalk/releases/latest/download/SHA256SUMS.txt)

Verify before installing: `sha256sum -c SHA256SUMS.txt`.

## What's in this release

- First public GitHub release.
- Universal APK (one file for every ARM phone).
- Signup now states plainly that there is **no password or account recovery**,
  and requires the user to acknowledge it. No email address or phone number is
  collected, so there is no recovery channel to store, leak, or attack.
- Release builds are R8-minified and Dart-obfuscated; mapping and symbol files
  stay private.
- SHA-256 checksums for every asset.

## Requirements

Android 7.0 (API 24) and newer. No phone number or email required.

## Notes

- Not on Google Play; sideload and update from inside the app.
- Direct media path (STUN). No TURN relay in the public service, so the
  strictest carrier NATs may not connect.
- Not open source. Source is proprietary; this repository hosts release builds.
