# Changelog

Release notes are published with each build on the
[Releases page](https://github.com/Stevechaapps/AyoooTalk/releases).

## 1.4.10 — 2026-11-25

- First public GitHub release.
- Universal APK plus split-per-ABI builds (arm64-v8a, armeabi-v7a).
- Release builds now run R8/minification and Dart obfuscation; mapping and
  symbol files are archived privately for crash reports.
- Signup now states plainly that there is no password or account recovery and
  requires the user to acknowledge it. The privacy design deliberately
  collects no email address or phone number.
- SHA-256 checksums for every asset.
- Public README, licence, security policy, and `llms.txt`.
